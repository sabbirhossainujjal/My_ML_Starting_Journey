# My_ML_Starting_Journey
`This repository contains all of practice code when i started learning Machine Learning back in 2019`


# Courses I have taken for learning ML
- [Python Programming Tutorials](https://www.youtube.com/watch?v=bY6m6_IIN94&list=PLi01XoE8jYohWFPpC17Z-wWhPOSuh8Er-)
    - This course was my introduction to python. I have learned about the basics of python.
    - **Learned topic**: Basics of Python - Data type, loop, function, classs, moudle importing
    - **Recommendation** : For beginners in programming, this course is a very good start, as it gives idea about data types, how to use different data type, for loop, while loop, fucntion, etc
    - **Rating**: 3/5 for beginners
- [Python for Everybody Specialization](https://www.coursera.org/specializations/python)
    - This was a more advance and detailed python course  
- [Machine Learning Course](https://www.coursera.org/learn/machine-learning-course)
    - My first introduction to machine learning. Andrew Ng is the boss of describing the concepts of ML. 
    - As a introductory course on ML, the course gives everything to get started with ML, hands on exercise for building machine learning model step by step from scratch, giving understanding the core concepts of ML. 
    - The course was designed with **Matlab** and I was learning matlab back then for my undergrad course requirements which give a heads up for it.
    - **Recommendation** : Highly recommended if anyone wants to start working on machine learning. The course was in Matlab back then but I think it has been redesigned with python which is very good as current all the ML related works are in python.
    - **Rating** : 4/5
- [Deep Learning Specialization](https://www.coursera.org/specializations/deep-learning)
    - This specialization gives the foundation of all the domains of deep learning from Computer Vision(CV) to Natural language processing (NLP).
    - The specialization has five course total, describing everything needed to work with deep learning, developing model from scratch, modifying existing models, hyper-parameters fine-tuning, structuring the whole workflow of deep learning models.
    - The course uses python for coding examples. Also it gives an introduction to tensorflow & Keras frameworks
    - The course quizes and coding problems are very up-to-date and structured which make sense as anyone go along the course.
    - **Recommendation**: Highly recommended to do the machine learning course before doing this specialization, it would be easy to work with some of the assignments and topics but it is mandatory.
    - **Rating** : 5/5
- [DeepLearning.AI TensorFlow Developer](https://www.coursera.org/learn/introduction-tensorflow)
    - This course gave me a deeper understanding on ternsorflow framework, how to work with tensorflow v1 which was very painful to be honest. Later in the course they shifted to the latest version of the tensorflow which makes life very easier. 
    - **Recommendation**: If anyone completed the deep learning specialization, i would not recommend it. I took it to get more deeper understanding on tensorflow but I think DL specialization covers all of it and PyTorch is very comfortable to work with than tensorflow.
    - **Rating** : 3/5

- [Statistics with Python](https://www.coursera.org/specializations/statistics-with-python)
    - This specialization is designed to teach learners beginning and intermediate concepts of statistical analysis using the Python programming language.
    - This courses gives confidence to work with statistical data covering topics such as understanding data through probabilistic theories, visualizing the data and getting the big picture from the data.
    - **Recommendation** : Highly recommended if someone wants to understand data more clearly especially through visualization.
    - **Rating** : 4/5

- [Mathematics for Machine Learning](https://www.coursera.org/specializations/mathematics-machine-learning)
    - Gives a better understanding what happening behind all these machine learning models.
    - The courses gives idea on linear algebra, calculus, PCA. The biggest advantage of these courses is the visualization and presentation which gives very clear idea on these topics which is very important if anyone wants to understand what is happening inside all these machine learning models
    - **Recommendation**: Highly recommend to anyone, even though someone is not want to work on ML, the topics are very relevant to any engineering background and these courses helps a lot to understand these topics.
    - **Rating** : 5/5

- [Finetuning Large Language Models](https://www.coursera.org/learn/finetuning-large-language-models-project)
    - This is more recent course I have done. It gives the hands on experience working with LLM finetuning for a particular task. It is a good starting workshop if anyone want to adpat LLM for any particular task, learn about how to configure LLM training perameters and strategy.
    - **Rating** : 3.5/5
